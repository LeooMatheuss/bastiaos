# BastiaOS Documentation

This directory contains the technical documentation for the BastiaOS project.

## Structure

- `architecture/` - System architecture and design documents
- `decisions/` - Architecture Decision Records (ADRs)
- `development/` - Development setup and workflow documentation
- `kernel/` - Kernel configuration and driver documentation
- `boot/` - Boot process and bootloader documentation
- `system/` - System services and init system documentation
- `filesystem/` - Filesystem layout and hierarchy documentation
- `networking/` - Network stack and configuration documentation
- `graphics/` - Graphics stack and display server documentation
- `packages/` - Package management and software documentation
- `security/` - Security policies and procedures
- `testing/` - Testing framework and procedures
- `releases/` - Release notes and version information

## Documentation Philosophy

Documentation is treated as first-class code. All technical decisions should be documented, especially significant architectural choices which are recorded as ADRs.

## Contributing

When adding documentation:

1. Place it in the appropriate subdirectory
2. Use clear, concise language
3. Include diagrams where helpful
4. Keep it up to date with code changes
5. Cross-reference related documents
