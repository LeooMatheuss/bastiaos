# BastiaOS

BastiaOS is a lightweight, secure-by-default Linux distribution built on **Ubuntu 26.04 LTS** with the **Xfce 4.20** desktop. It reuses the proven Ubuntu core — signed kernel and boot chain, drivers, security updates — and curates everything on top: no silent snaps, no telemetry, no services without a reason.

> **Your system. Your fortress.**
